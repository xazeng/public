# 问问 GPT隐私政策

生效日期：2026 年 11 月 16 日

问问 GPT（以下简称“本扩展”）由 zen 开发。本政策说明本扩展在提供当前网页分析和问答功能时如何处理用户数据。如有问题，请联系 `wszxayx@gmail.com`。

## 单一用途

本扩展的单一用途是在用户主动操作时读取当前网页的必要内容，将其提交给用户自行选择并授权的 OpenAI API，以便在 Chrome 侧边栏中提供网页总结、选中文字解释和基于当前网页的问答。

## 处理的数据

只有当用户点击发送或快捷操作时，本扩展才会处理以下数据：

- 当前标签页的标题和 URL；
- 当前网页受限长度的可见正文；
- 用户在网页中主动选中的文字；
- 当前网页可见交互元素的角色和名称摘要；
- 用户在侧边栏中输入的问题；
- 当前标签页最近的有限条数对话；
- 用户自行填写的 OpenAI API Key、模型选择和是否在本机记住 Key 的设置。

本扩展不读取输入框当前值，不读取密码框内容，不在后台持续收集浏览历史，不包含广告、行为分析或第三方统计代码。

## 数据的用途和共享

上述网页内容、问题和有限对话只用于生成用户主动请求的回答。它们会由本扩展通过 HTTPS 直接发送到 OpenAI API（`api.openai.com`），不会经过开发者运营的服务器，也不会出售给第三方或用于广告、信用评估及其他无关目的。

OpenAI 对相关数据的处理受用户自己的 OpenAI API 账户设置、OpenAI 适用条款和隐私政策约束。用户应自行确认其 API 账户的数据控制和保留设置是否满足需要。

本扩展对从 Chrome API 获得的信息的使用遵守 Chrome Web Store 用户数据政策及其“有限使用”要求；数据只用于本政策说明的用户可见功能。

## API Key 和本地存储

- 默认情况下，OpenAI API Key 保存在 `chrome.storage.session`，Chrome 完全退出后失效。
- 只有用户主动勾选“在本机记住 API Key”时，Key 才会保存在 `chrome.storage.local`。
- API Key 仅用于用户主动发起的 OpenAI API 请求，不会发送给开发者服务器。
- 本机上的其他高权限软件、浏览器漏洞或设备账户可能读取本地数据，因此不应在共享或不可信设备上选择长期保存 Key。

模型选择和“是否记住 Key”的设置保存在扩展本地存储中。对话按标签页保存在当前 Chrome 会话中，用户可以点击“清空”删除当前标签页对话；标签页关闭后，本扩展会清理该标签页的会话对话。

首次使用时，本扩展会在产品界面内显示主要数据处理方式。只有用户点击“同意并继续”后，扩展才会读取标签页、申请网站权限、保存 API Key 或调用 OpenAI API。用户可以随时在设置中撤回同意；撤回会停止当前请求，并清除 API Key 和当前 Chrome 会话中的全部标签页对话。

## 网站权限

本扩展不会在安装时要求访问所有网站。用户首次要求分析某个网站时，Chrome 会显示该网站的权限请求。用户拒绝授权后，本扩展不会读取或发送该页面内容。Chrome 内置页面、Chrome Web Store 等受保护页面不会被读取。

## 数据保留与删除

开发者不运营用于接收或保存网页内容、对话、API Key 的服务器。本扩展本地保存的数据可通过以下方式删除：

- 点击侧边栏中的“清空”删除当前标签页对话；
- 关闭相关标签页或完全退出 Chrome，清理对应的会话数据；
- 在设置中取消本机记住并保存，移除持久保存的 API Key；
- 卸载本扩展，删除由 Chrome 管理的扩展本地数据。

已经直接发送到 OpenAI API 的数据，其保留和删除由 OpenAI 及用户的 API 账户设置决定。

## 安全

本扩展使用 HTTPS 与 OpenAI API 通信，并限制网页提取范围。网页内容被视为不可信数据，模型被要求忽略其中试图改变权限或泄露信息的指令。但任何软件和模型防护都无法保证绝对安全，用户不应在不必要的情况下提交敏感网页内容。

## 政策变更

如果本扩展的数据处理方式发生实质变化，将在新版本发布前更新本政策，并按 Chrome Web Store 要求在产品界面中进行必要告知和征得同意。本政策顶部的生效日期会同步更新。
